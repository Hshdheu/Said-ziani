# Photo2Slides - Android

قالب مبدئي لمشروع Android لتحويل الصور والنص إلى فيديو (skeleton).

المحتويات:
- هيكل تطبيق Android (Kotlin + Jetpack Compose) بسيط.
- ملفات نموذجية: app/src/main/AndroidManifest.xml, MainActivity.kt, build.gradle مبدئياً.
- ملف GitHub Actions بسيط للبناء، وملف تذاكر backlog بصيغة CSV.

ملاحظة: هذا repo يحتوي على هيكل مبدئي (skeleton). ستحتاج لتحديث ملفات Gradle واضافة Gradle wrapper قبل البناء الحقيقي على CI.
